# The Tuna Buyers Guide: IPNLF webinar

Registration page for IPNLF's webinar on *The Tuna Buyers Guide* (10 December 2026). Registration goes to the Zoom webinar's own sign-up form.

Static HTML with no build step: `index.html` plus the images in `img/`. Hosted on Netlify from the `main` branch.

## Editing

- **Speakers:** edit the `SPEAKERS` list near the bottom of `index.html`. Add a photo to `img/` and reference it with `photo: "img/..."`. An entry with no name shows as "To be confirmed".
- **Zoom link:** appears on the three Register buttons; search `index.html` for `zoom.us`.
- The page has `<meta name="robots" content="noindex">`, so search engines won't list it. Remove that line if it should be findable through Google.

Speaker photos are used with the speakers' permission. Principle icons come from *The Tuna Buyers Guide 2026*.
